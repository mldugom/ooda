# Profiles

A profile answers: **what expertise should the active role bring?**

Profiles are lightweight and composable. They should not create new autonomous agents by default.

## V1 profile families

### ML / data
- `quantitative-research`
- `statistics`
- `data-science`
- `ml-research`
- `ml-engineering`
- `data-engineering`

### AI
- `llm-engineering`
- `agent-systems`
- `evaluation`
- `retrieval`

### Software / product
- `backend`
- `frontend`
- `full-stack`
- `api`
- `browser-extension`
- `saas`
- `analytics-product`
- `automation`

### Finance
- `quant-markets`
- `fundamental-valuation`
- `portfolio-construction`
- `market-microstructure`
- `risk`

### Operations
- `reliability`
- `deployment`
- `observability`

Profiles may be extended by projects. The role remains the authority boundary.
